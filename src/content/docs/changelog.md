## 旧フォルダーからの移行

参照プロジェクトには、AMSE 系とは別に `Assets/ALBUSMACHINERY/LoadGauge/` と `Assets/ALBUSMACHINERY/RaderAltimeter/` が存在します。名前が似ていても、同じスクリプト・設定であるとは限りません。

1. 既存の計器に付いているコンポーネント名を確認します。
2. 旧 Controller が Animator を更新している場合、新しい Controller と二重更新しない構成にします。
3. Animator 名、最大値、単位、参照を移行先の設定表で確認します。
4. 作業用コピーで動作を確認してから、使用中の機体へ反映します。

現時点で、自動移行ツールや一律の互換性はありません。

## 姿勢計の旧設定

参照した BallAttitudeIndicator Prefab には、現行スクリプトにない ControlledFlip 関連の保存値があります。現行 Basic 版の記事では、存在する項目と対応姿勢範囲だけを掲載しています。

## 更新時に記録すること

アドオンの配布バージョン、変更した設定、依存バージョン、既存機体の再設定が必要か、確認した環境と結果を記録します。記事の設定表と Prefab の保存値を一緒に見直します。
