SaccFlightAndVehicles 用アドオンパッケージです。計器、エンジン・飛行挙動、サウンド、照準表示などの機能を追加できます。各アドオンのページで、導入手順と設定項目を確認できます。

## アドオン一覧

| アドオン | 説明 |
| --- | --- |
| [AMSE_BallAIController](./addons/ball-ai/) | 機体のロール・ピッチに追従する球形姿勢計 |
| [AMSE_RadarAltimeterController](./addons/radar-altimeter/) | 対地距離と Decision Height を表示する電波高度計 |
| [AMSE_LoadGaugeController](./addons/load-gauge/) | Grapple に接続した吊り荷の質量を表示する荷重計 |
| [AMSE_FlightInstruments_TypeA](./addons/flight-instruments/) | 高度、燃料、速度、昇降率、方位などを表示する計器セット |
| [AMSE_RotorStall](./addons/rotor-stall/) | 高入力の継続によるローター失速と推力の回復 |
| [AMSE_HeliGroundCyclic](./addons/heli-ground-cyclic/) | 接地中の前方サイクリック入力に応じた推力角の補正 |
| [AMSE_EngineStartupRespawnReset](./addons/engine-startup-reset/) | 始動中のリスポーン時にアニメーションと表示をリセット |
| [AMSE_SoundController](./addons/sound-controller/) | 始動音、機内外の音の切り替え、エンジン音のピッチを補助 |
| [AMSE_SightView](./addons/sight-view/) | 頭に追従する照準映像と照準器の展開表示 |
| [AMSE_AnimatorParameterRelay](./addons/animator-relay/) | Animator 間で Bool / Int / Float のパラメーターを転送 |
