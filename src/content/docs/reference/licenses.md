## 配布について

アドオン本体の配布先は、現在未確定です。このサイトは導入・設定のマニュアルです。配布先が決まり次第、アドオン一覧と各記事から案内します。

GitHub の文書リポジトリには、Unity の機体モデル・テクスチャ・音声・アドオン本体は含めません。

## アドオンのライセンス

参照した AMSE フォルダーと Shared フォルダーには、MIT 形式の `LICENSE.txt` が置かれています。実際に使用・再配布する場合は、取得したパッケージ内のライセンスと著作権表示を確認してください。

SaccFlightAndVehicles 由来の機能については、Sacchan-VRC の著作権表示も同梱されています。改変・再配布時には、各アセットの表示を維持します。モデル、画像、音声などの利用条件は、それぞれの配布物で確認します。
